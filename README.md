# Advanced Features

Advanced features patch with (hopefully) a variety of code features.

## Description

This repository contains a collection of advanced features and patches including:

- Wearable attachment bypass functionality
- RuckSack/Backpack system enhancements
- Ground storage improvements
- Quartz light system integration
- Networking and packet handling

## Building

### Requirements
- .NET Framework / .NET Core
- Visual Studio or equivalent C# IDE

### Build Instructions

**PowerShell:**
```powershell
.\build.ps1
```

**Bash/Linux:**
```bash
./build.sh
```
